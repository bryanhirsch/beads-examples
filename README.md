# Example

Create a bead for each of these:

1. Create a “Hello world!” script I can run in my terminal.

2. Update static “Hello world” script to a dynamic “Hello $name” script. Accept name as an argument. If no arg is passed, use “world”.

3. Update new script to take an either a name param or a path to a file with a list of names. If a file is passed, say hello to each person listed in the file.

4. Create a file of names I can use with my hello world script.
